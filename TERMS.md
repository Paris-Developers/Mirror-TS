When using Mirror, don't:

## Server managers

If you add Mirror to a server, or have manager access to it, you are responsible for how Mirror is set up there:

- **NSFW commands** are off by default. Only turn them on in a server where everyone is an adult and has agreed to that kind of content.
- **Embed fix** reposts links under Mirror's name. If your server filters links or moderates what people post, make sure those rules also cover Mirror's posts.
- **Silencing** members or roles stops them from using intros, music and birthdays in your server. Use it fairly.
